= Prerequisites and Logistics
:navtitle: 2. Prerequisites and Logistics

== Infrastructure Requirements

The core requirement is simple: a *pre-deployed Ansible Island Adventure environment* ordered from the https://catalog.demo.redhat.com[Red Hat Demo Platform (RHDP)].

The RHDP catalog item provisions a shared OpenShift CNV cluster with all services pre-deployed:

* *Ansible Automation Platform 2.7* — Gateway and Controller, with per-instructor organizations
* *CTFd* — Per-instructor CTF scoring instances
* *Gitea* — Shared Git hosting with per-instructor repositories
* *Red Hat OpenShift Dev Spaces* — Browser-based IDE for participants
* *RHEL 9 managed nodes* — One VM per instructor, provisioned via OpenShift Virtualization
* *MariaDB and Redis* — Backend databases for CTFd instances

[IMPORTANT]
====
No manual installation is required. The environment arrives fully deployed from RHDP. Plan for adequate *lead time* when ordering — provisioning takes approximately 60 minutes.
====

== Staffing and Facilitator Roles

A successful event requires proper staffing:

[cols="1,2,3",options="header"]
|===
| Group Size | Recommended Staff | Notes

| 5–15 participants
| 1 facilitator + 1 roamer
| Minimum viable event

| 15–30 participants
| 1 facilitator + 2 roamers
| Most common event size

| 30–60 participants
| 1 facilitator + 3–4 roamers
| Requires experienced team

| 60+ participants
| 1 facilitator + 1 roamer per 15 participants
| Consider splitting into heats
|===

*Roles:*

* *Facilitator* — Runs the event, manages pacing, introduces challenge categories, leads the debrief. The facilitator should have completed this lab.
* *Roamer* — Circulates among participants to provide hints, troubleshoot access issues, and keep the energy high. Roamers should have played through the challenges at least once.

== Pre-Event Preparation Checklist

Complete these tasks *before the event day*:

=== Environment

* [ ] Order the "Ansible Island Adventure" catalog item from RHDP with sufficient lead time
* [ ] Verify the environment is fully provisioned and all services are accessible
* [ ] Confirm the number of available instructor/participant slots matches your expected attendance

=== Materials

* [ ] Download and distribute player credential handouts (generated by the deployer — see Module 5)
* [ ] Create shortened URLs (e.g., using go.redhat.com or bit.ly) for CTFd, Gitea, and AAP
* [ ] Print the pirate-themed facilitation guide or have it open on a facilitator device
* [ ] Prepare a brief slide deck for the introduction (15–20 minutes of context before the hands-on portion)

=== Venue

* [ ] Confirm venue Wi-Fi can support participant connections to the OpenShift cluster
* [ ] Arrange desks for collaborative work — small groups of 3–5 work best
* [ ] Ensure every participant has a laptop with a modern web browser
* [ ] Test participant connectivity to the cluster from the venue network (firewall rules may block OpenShift routes)

== Room Setup and Pacing

=== Typical Event Timeline

[cols="1,2,3",options="header"]
|===
| Time | Activity | Notes

| 0:00–0:15
| Welcome and introduction
| Explain the format, hand out credentials, set expectations

| 0:15–0:25
| Account setup and Warm Up
| Everyone should complete "Write your name in the sand" and "Unlock the island"

| 0:25–1:30
| Challenge time
| Self-paced. Facilitator monitors leaderboard and provides pacing cues

| 1:30–1:50
| Final push
| Announce time remaining. Encourage hint usage for stuck participants

| 1:50–2:00
| Debrief and wrap-up
| Leaderboard review, key takeaways, next steps

| 2:00–2:30
| Open networking (optional)
| Allow participants to continue or discuss
|===

=== Pacing Tips

* *Start together.* Everyone should complete the Warm Up challenges before moving on. The facilitator provides the "Unlock the island" key to gate progress.
* *Check the leaderboard.* If most participants are stuck at the same point, provide a group hint.
* *Don't rush.* The Treasure Hunt challenges are where the deepest learning happens. Give participants time to work through them.
* *Adjust for audience.* Technical audiences may skip Warm Up quickly; non-technical audiences may need more roamer support during At the Beach.

== Key Takeaways

* A pre-deployed Ansible Island Adventure environment ordered from RHDP is the core infrastructure requirement.
* Pre-event preparation — environment ordering, credential distribution, handout creation — must be completed before the event day.
* Staffing ratios and facilitator roles are critical for a smooth event experience.
* The customer-facing event is typically 2–3 hours and can be adjusted for different group sizes and skill levels.
