# Module 06 — Wrap-up and next steps

### Brief Overview

This closing module provides attendees with the resources they need to independently run Ansible Island Adventure events. It covers access to the deployment repository and event assets, guidance on customizing challenges for specific audiences, and an open Q&A session for experience sharing. Attendees leave with everything required to plan, deploy, and deliver their own customer-facing CTF events.

### Audience and Time

- **Personas:** Solution Architects, TAMs, partner engineers
- **Prerequisites for this module:** Completion of Modules 1-5
- **Estimated duration:** 10 minutes

### Learning Objectives

- Configure challenge definitions, difficulty tiers, and content to tailor Ansible Island Adventure for specific customer use cases or partner engagements
- Verify access to the deployment repository and all event assets required to independently run future events

### Lab Structure

| Section | Title | Duration |
|---------|-------|----------|
| 1 | Access to resources and assets | 3 min |
| 2 | Customization guidance | 4 min |
| 3 | Open Q&A and experience sharing | 3 min |

### Detailed Steps

1. Confirm access to the Ansible Island Adventure deployment repository containing the Ansible playbook, challenge definitions, and all supporting automation
2. Review the full set of event assets: facilitation guides, handout templates, shortened URL configuration, and branding materials
3. Walk through how to add new challenges: where challenge definitions live, how to set point values, and how to create new flags
4. Review how to adjust difficulty tiers to match the target audience: removing advanced challenges for beginner groups or adding harder challenges for experienced teams
5. Discuss options for branding and customizing the event for specific customer engagements or partner events
6. Open the floor for Q&A: answer questions about deployment, facilitation, customization, or pipeline follow-up
7. Share experiences from previous Ansible Island Adventure events and discuss lessons learned

### Key Takeaways

- All deployment automation, challenge content, and event assets are available in the repository for independent use
- Challenges can be customized — added, removed, or adjusted in difficulty — to match the target audience
- Attendees now have everything they need to independently deploy, facilitate, and follow up on Ansible Island Adventure events
- The community of facilitators is a resource — sharing experiences improves future events

### Infrastructure Notes

No additional infrastructure is required for this module. Attendees should confirm they can access the deployment repository before leaving.
